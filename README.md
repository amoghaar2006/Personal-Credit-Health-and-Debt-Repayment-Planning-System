# Personal Credit Health and Debt Repayment Planning System

**Database Management Systems – Mini Project**  
PES University | B.Tech – Computer Science and Engineering

## 📌 Project Overview

The **Personal Credit Health and Debt Repayment Planning System** is a database-driven project designed to manage users' financial profiles, loan information, repayment records, and structured debt repayment plans.

The system maintains financial information and repayment details in a relational database, enabling organized data management, credit health monitoring, and repayment planning.

## 🎯 Project Objectives

- Maintain user financial profiles and credit-related information.
- Store and manage loan details and repayment records.
- Track payment statuses, outstanding balances, and overdue payments.
- Generate structured debt repayment plans.
- Perform database operations and retrieve meaningful financial insights using SQL queries.
- Maintain data integrity through primary keys, foreign keys, and database constraints.

## 🗄️ Database Design

The project consists of six main relational tables:

| Table | Description |
|---|---|
| USER | Stores user information. |
| FINANCIAL_PROFILE | Maintains users' financial profiles. |
| LOAN | Stores loan-related information. |
| REPAYMENT | Maintains loan repayment records. |
| REPAYMENT_PLAN | Stores structured repayment plans. |
| PLAN_PAYMENT | Maintains individual payments associated with repayment plans and loans. |
